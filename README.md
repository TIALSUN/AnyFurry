# AnyFurry

AnyFurry 是一个用来在 Blender 里捏兽装头壳的小插件。想让口鼻短一点、眼睛挪一点，或者试试另一种脸型，都可以从自带的基础模型开始，边调参数边看效果。现在也能调整眼孔、嘴孔和对称减重孔，保存自己的方案，再导出 STL。做它的想法很简单：希望把反复改模型的过程变得顺手一点，让更多时间留给自己喜欢的角色。项目还在慢慢打磨，欢迎来试试，也欢迎把用着别扭的地方告诉我。

当前版本：**v0.29.0 · Beta**，在 **Blender 5.2.0 LTS** 上完成软件验证。

[下载安装包](https://github.com/TIALSUN/AnyFurry/releases/tag/v0.29.0) · [使用说明](blender_addon/anyfurry_mouth/README.md) · [反馈问题](https://github.com/TIALSUN/AnyFurry/issues)

安装包自带基础模型；下载 `AnyFurry_Beta1.zip` 后，在 Blender 的插件设置中选择“从磁盘安装”，无需先解压。实物打印和佩戴测试还没完成，准备制作前请按自己的材料、工艺和尺寸检查模型。
