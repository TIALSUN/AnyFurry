# AnyFurry 捏脸 · Beta 1 · v0.29.0

在 Blender 中调整最终版头壳比例、鼻嘴形态，以及左右对称的眼孔和嘴孔。安装包包含模型，不需要另外下载。基础模型仍是已确认的最终版 v0.27.0，本次优化不改变默认外形。

## 安装与找到面板

本版要求 Blender 5.2 或更高版本，实际验证版本为 5.2.0 LTS。其他版本未验证；旧版插件先禁用再升级，避免同时使用两个版本。

1. 保留自己的 .blend 工程，无需删除旧模型。
2. 打开 Blender 的“编辑 → 偏好设置 → 插件”页面。
3. 使用插件页面菜单中的“从磁盘安装 / Install from Disk”，选择 AnyFurry_Beta1.zip，不要先解压。
4. 搜索 AnyFurry，勾选启用。名称应包含 v0.29.0。
5. 升级后重启 Blender。在三维视图按 N 打开侧栏，点击 AnyFurry 标签。
6. 点击“打开最终版头壳 / 继续编辑”。也可在三维视图按 F3 搜索 AnyFurry 基础捏脸。

未出现面板时，检查鼠标是否在三维视图、插件是否已启用、是否处于物体模式，以及版本号。按 Tab 可退出编辑模式。“正面查看”会把模型切换到正面正交视图。

## 首次使用

- 整体比例：整体宽度、整体高度、额头高度、眼部以下高度。
- 鼻嘴形态：口鼻部长度、口鼻部宽度、鼻嘴整体上下位置。
- 眼部开孔：1/2/3 号眼型三选一；眼距、上下位置、角度、宽度和高度。
- 嘴部开孔：开口大小、嘴孔宽度、下沿圆弧和侧缝；保留上扬嘴角与向内收的孔壁。
- 减重孔：额头、顶部、两侧的左右对称圆孔；调整孔径、保留间距和疏密，先预览再生成。
- 保存与导出：可编辑工程、参数预设、毫米制 STL 和全部复位。

分组标题可折叠。滑块 0 值为最终版状态；毫米、百分比和角度说明显示在旁边或下方。口鼻部宽度改变外形，嘴孔宽度改变孔的跨度。侧缝显示的是参考参数，不能当作孔壁任意位置的实测宽度。

基础范围：嘴长缩短最多 15 mm / 伸长最多 25 mm；口鼻宽度 ±15%；鼻嘴主体上下 ±8 mm；整体宽高 ±10%；额头高度 ±15%；眼部以下高度 ±12%。局部形变边界平滑衔接。

脸颊饱满度继续永久排除。旧嘴孔角度值不参与计算。

## 刷新与流畅度

默认开启自动更新和快速拖动预览。快速预览会在调节期间暂时隐藏开孔，停止约 0.35 秒后计算并恢复实体孔。关闭“快速拖动预览”可保持原显示方式。

计算仍慢时，可关闭“自动更新开孔”，调节结束后点击“更新 / 重试”。高面数头壳的最终布尔计算仍需要时间；这不是即时渲染开关。保存和导出前都会更新，即使处于手动模式。

失败时面板显示原因，保留上一次有效孔的形状和显示状态。调整参数后点击“更新 / 重试”。失败时拒绝专用 STL 导出，避免交付不匹配的结果。

## 减重孔

默认关闭，保留既有工程和最终模型的外形。展开“减重孔”，启用后按额头、顶部、两侧选择区域。孔径范围 8–26 mm，默认 18 mm；保留间距范围 4–20 mm，默认 8 mm；疏密为疏、中、密。

这些数值是可调设计起点，不是已验证的材料或打印强度阈值。打印方式和材料尚未确定，尚无实物验证。保留间距用于孔间、眼嘴孔、后沿的几何避让；顶部和两侧会因表面倾斜在正面看成椭圆。

调参数后，显示贴合表面的孔位轮廓，并自动跳过靠近眼嘴开口、两个后沿切口和其他孔的候选孔位。保留中央连续骨架。默认全区域中等布局生成 22 个孔；孔数会随孔径、间距、眼嘴和捏脸状态变化。

点击“生成 / 更新减重孔”才计算实体孔。改变捏脸、眼嘴或减重孔参数后，已有减重孔暂时关闭，保留上一次切刀几何，等待确认新布局后重新生成。“更新眼嘴 / 孔位”只更新眼嘴实体孔与减重孔预览。预览轮廓和切刀不混入 STL。

生成前后检查闭合性、单一连通性和正体积；失败时回退切刀与修改器，保留错误原因供重试。成功后显示实体材料体积减少比例，不等同于带毛皮、填充和配件的整头重量变化。默认约减少 5.5%。

预览状态可以保存为可编辑工程，但专用 STL 导出要求减重孔已经生成且与当前参数一致；否则提示先生成或关闭减重孔。Blender 自带或第三方导出器不执行这个插件检查。

参数预设升级为 schema 2，包含减重孔设置。仍可载入 schema 1 旧预设，载入后减重孔关闭。对象非等比例缩放或剪切会拒绝生成；插件内捏脸滑块正常支持。

## 继续编辑与新建

选中摄像机、辅助物体或空白处后，面板继续控制当前头壳。“打开最终版头壳 / 继续编辑”优先使用已有头壳，不重复添加。

另一份设计请使用“新建独立头壳”。每份头壳使用独立场景和参数，从 Blender 顶部场景列表切换。当前流程按每场景一份可调头壳设计，避免手动复制到同一场景后共享开孔工具。

## 保存与预设

- 保存可编辑工程：保存完整 .blend，包括当前各场景、模型和参数。
- 保存参数：保存小型 JSON，只包含捏脸和开孔参数，不含模型，适用于相同最终版。
- 载入参数：先验证格式和范围，再应用；无效文件不覆盖现有参数。
- 恢复全部默认值：恢复基础滑块、1 号眼型和默认开孔，可撤销。

旧场景缺少鼻嘴上下滑块时，使用“升级：启用鼻嘴上下位置”。原有基础形状不变。重新打开、撤销和重做后，插件检查开孔与参数一致性。

Blender 原生保存也会更新开孔。计算失败时，原生保存仍允许保存以避免丢失工作，并记录警告；之后应重试核对开孔。专用工程保存按钮会阻止尚未成功更新的提交。

## 导出当前头壳

“导出当前头壳 STL（毫米）”只导出当前头壳求值结果，包含启用的实体眼孔、嘴孔和已生成的减重孔；切刀、预览轮廓、摄像机、灯光及其他场景不混入。关闭开孔开关时，该孔不出现在导出文件里。

导出前完成刷新，检查闭合性和连通性，并把世界坐标及场景单位转换为毫米。在一次性导出副本上，以 0.005 mm 阈值处理布尔三角化产生的微小退化几何，再检查闭合性。最终版资产和可编辑头壳不执行这项清理。

STL 不保存可调参数；继续捏脸请保留 .blend。软件网格检查不代替打印、装配和佩戴验证。

## 隐私与发布管理

当前发行版仅内置脱敏后的最终模型，移除了本机目录和编辑器历史；模型网格与形态键保持一致。插件异常提示遮蔽常见用户目录路径。本包不含编译缓存和模型备份。
